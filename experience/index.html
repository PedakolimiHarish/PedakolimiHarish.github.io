Project Ember

Open Source AI Companion Robot Platform

Project Ember is an open-source robotics platform focused on autonomous navigation, embedded software, computer vision, ROS 2, and AI-assisted interaction. The project is currently in its concept and platform architecture phase.

  • ROS 2
  • C++
  • Python
  • OpenCV
  • Embedded Linux

Project Ember is designed as a modular robotics platform that combines embedded firmware, ROS 2, computer vision, AI interaction, and web technologies into a single extensible architecture.

The current focus is on platform development, including hardware integration, motion control, software architecture, and reusable robotics components before introducing higher-level AI capabilities.

Once the robotics platform reaches maturity, the project will expand toward intelligent companion behaviors, perception, memory, and natural human-robot interaction.
