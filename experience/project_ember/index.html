Project Ember

Modular Personal Robotics Platform

Project Ember is a modular personal robotics platform designed to combine companion, security, and AI capabilities into a single autonomous mobile robot. The platform emphasizes scalability, maintainability, and professional engineering practices while serving as an open-source robotics research platform.

  • ROS 2
  • Modern C++
  • Python
  • Linux
  • STM32
  • OpenCV
