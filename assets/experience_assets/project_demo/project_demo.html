    Project Overview

    Project test is designed as a modular robotics platform that combines embedded firmware, ROS 2, computer vision, AI interaction, and web technologies into a single extensible architecture.

    The current focus is on building and validating the core robotics platform before introducing higher-level AI capabilities. This includes hardware integration, motion control, software architecture, sensor integration, and reusable robotics components.

    The platform is intended to provide a foundation on which different autonomous and interactive capabilities can be developed without tightly coupling the higher-level intelligence to the robot's low-level control systems.

    Once the platform reaches maturity, Project test will expand toward intelligent companion behaviors, perception, memory, person recognition, and natural human-robot interaction.
