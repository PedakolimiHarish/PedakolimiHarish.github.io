Mobile 3D Printer

Mobile Robotic Platform for Large-Scale Construction 3D Printing

Mobile 3D Printer is a simulation-validated concept for a mobile robotic platform designed for continuous, large-scale construction 3D printing. The project combines a differential-drive mobile base with a cylindrical manipulator and extrusion tool, with the long-term goal of printing complete structures such as houses.

    Project Overview

    The project explores a mobile robotic construction 3D printer designed to overcome the fixed workspace limitations of conventional large-format printers. The platform combines a differential-drive mobile base with a cylindrical robotic manipulator carrying an extrusion tool, allowing the printer to reposition itself while continuing the construction process.

    The current implementation focuses on idea and architecture validation through a complete Gazebo simulation. The simulation was used to evaluate the overall robotic concept, including mobile-base movement, manipulator operation, printing workflows, and the interaction between the mobile platform and printing system.

    The software architecture was designed around a layered robotics approach: deterministic firmware for motion execution, ROS 2 for robot control and localization, ROS 2-based verification and visualization, G-code/toolpath processing, and coordinated mobile-base and manipulator motion

    The long-term objective is a system capable of large-scale, continuous construction printing, where the robot can move through a construction site while depositing material and progressively building a complete structure. The current simulation represents an initial feasibility and architecture study; physical development is planned for a later phase, with the architecture expected to be substantially revisited when hardware development begins.
